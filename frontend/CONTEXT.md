# Frontend

使用者介面：上傳、Job 列表、Job 工作區（來源／對話／Studio 三欄）。這裡只收錄這個 context 特有、
容易混淆的詞彙，不是完整的功能清單——功能範圍見 `README.md`。逐字稿本身的詞彙（片段、編輯、講者…）
見 `../transcription-service/CONTEXT.md`。

## Language

**匯出**：
把一個 Job **已經存在**的內容（逐字稿、譯文、摘要、章節、問答紀錄、筆記、測驗、決策、事實查核的結果、原始媒體檔）轉成檔案讓使用者下載或
複製，不呼叫 LLM、不產生新內容。

**雙語**：
逐字稿每個片段原文在上、譯文在下（畫面的「顯示」與匯出的雙語 TXT／字幕都是）；還沒有譯文的片段只有原文。
_Avoid_: 對照、bilingual subtitles 以外的叫法
_Avoid_: 多格式輸出、export outputs（那是 ai-service 用 LLM 生成新文件，見 `../ai-service/CONTEXT.md`）

**目前片段**：
播放時間落在其起訖時間內的片段。播放時間落在兩個片段之間的空隙時沿用前一個；在第一個片段之前、
最後一個片段結束之後都沒有目前片段。
_Avoid_: 當前段落、播放中的句子

**自動跟隨**：
逐字稿隨播放自動捲動、讓目前片段保持在視野內的狀態。使用者手動捲動、搜尋或編輯時會暫停；只有
使用者明確要求「回到播放位置」，或主動跳到某個時間點（點逐字稿時間戳、章節、問答引用）才恢復。
_Avoid_: auto-scroll、同步捲動

**筆記標記**：
逐字稿上，釘了時間的筆記標在它落在的片段時間戳旁。落在兩個片段之間的空隙時標在前一個片段；比第一個片段還早的
標在第一個片段（跟目前片段不同：筆記一定要標得出來）。筆記本身見 `../upload-service/CONTEXT.md`。
_Avoid_: 書籤圖示、註記
